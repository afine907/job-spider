# 招聘网站爬虫系统 - 企业级架构设计

> 基于 Google 架构原则设计：可扩展性、可观测性、容错性、安全性

---

## 一、项目背景

**目标**：构建一个招聘数据采集系统，定期爬取主流招聘网站数据，用于个人求职分析。

**核心价值**：
- 薪资行情分析（各行业、岗位薪资分布）
- 技能需求趋势（热门技能、新兴技术）
- 地域岗位分布（城市/区域机会对比）
- 职业发展路径分析

---

## 二、架构设计原则

```
┌─────────────────────────────────────────────────────────────────┐
│                    Google 架构设计原则                           │
├─────────────────────────────────────────────────────────────────┤
│  1. 设计为失败 (Design for Failure)                              │
│     - 每个组件都可能失败，系统需具备容错能力                        │
│                                                                  │
│  2. 可观测性优先 (Observability First)                           │
│     - Logs + Metrics + Tracing 三位一体                          │
│                                                                  │
│  3. 渐进式扩展 (Scale Gradually)                                 │
│     - 从单机到分布式，架构支持平滑演进                             │
│                                                                  │
│  4. 安全纵深防御 (Defense in Depth)                              │
│     - 多层安全策略，降低单点风险                                   │
│                                                                  │
│  5. 数据即资产 (Data as Asset)                                   │
│     - 数据质量、血缘、版本全程可追溯                               │
└─────────────────────────────────────────────────────────────────┘
```

## 四、技术选型

| 层级 | 组件 | 选型 | 选型理由 |
|------|------|------|----------|
| **语言** | Python 3.11+ | ✅ | 异步支持好，生态丰富 |
| **HTTP客户端** | httpx | ✅ | 支持同步/异步，API友好 |
| **浏览器模拟** | DrissionPage | ✅ | 轻量，过反爬能力强 |
| **HTML解析** | parsel | ✅ | Scrapy同款，支持XPath+CSS |
| **数据验证** | Pydantic v2 | ✅ | 类型安全，性能优秀 |
| **数据库ORM** | SQLAlchemy 2.0 | ✅ | 成熟稳定，异步支持 |
| **数据库** | SQLite → PostgreSQL | ✅ | 初期SQLite，后期可迁移 |
| **任务调度** | APScheduler | ✅ | 轻量，满足需求 |
| **配置管理** | pydantic-settings | ✅ | 类型安全，环境变量 |
| **日志** | structlog | ✅ | 结构化日志，生产级 |
| **测试** | pytest + pytest-asyncio | ✅ | 异步支持，插件丰富 |
| **包管理** | pip + venv | ✅ | 简单直接，Python 原生支持 |

## 五、目标网站优先级

| 网站 | 优先级 | 原因 |
|------|--------|------|
| 智联招聘 | ⭐⭐⭐⭐⭐ | 反爬相对温和，数据量大 |
| 前程无忧(51job) | ⭐⭐⭐⭐ | 老牌平台，数据质量稳定 |
| Boss直聘 | ⭐⭐⭐ | 数据活跃，但反爬严格 |

## 六、反爬策略矩阵

```
┌──────────────────────────────────────────────────────────────────────────┐
│                         反爬策略矩阵                                      │
├──────────────┬───────────────┬───────────────┬───────────────────────────┤
│    策略       │    实现难度   │    有效性     │         说明              │
├──────────────┼───────────────┼───────────────┼───────────────────────────┤
```
